### Open source

**[perepost](https://github.com/smotim/perepost)** — self-hosted Go bot that mirrors Telegram
channel posts to MAX channels: formatting, media, albums, many-to-many routes.

**[socialiteproviders-telegram-oidc](https://github.com/smotim/socialiteproviders-telegram-oidc)** —
Telegram OIDC provider for Laravel Socialite: Authorization Code + PKCE, JWT validation.
Submitted upstream: [SocialiteProviders/Providers#1495](https://github.com/SocialiteProviders/Providers/pull/1495).

SDKs for Russian freight carriers that I use in production:

- [sdk-kit-api](https://github.com/smotim/sdk-kit-api) — KIT API, order field mapping and model fixes
